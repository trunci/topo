# Paper — self-contained build

Everything in this folder is **generated**; do not edit by hand.

- `PAPER.md` — the paper. Every number is interpolated from `../results/*.json`
  by `src/write_paper.py`; no value is hand-typed.
- `figures/` — generated by `src/make_figures.py` from the same stats JSONs.
- `PAPER.pdf` / `PAPER.html` — rendered by `src/md_to_pdf.py` (headless Chrome).
- `PAPER_ieee.docx` — IEEE conference (letter, two-column) rendering of the same
  PAPER.md, generated by `src/write_ieee_docx.py` into `ieee_template.docx`
  (IEEE's unmodified Strict-OOXML template; converted to Transitional on the
  fly by `src/ieee_template_convert.py`).

Regenerate everything from the repo root:

```
uv run python -m src.make_figures
uv run python -m src.write_paper
uv run python -m src.md_to_pdf
uv run python -m src.write_ieee_docx
```

Per-experiment verdicts live in `../FINDINGS_exp*.md`; pre-registrations are
written into those files before each run (see `FINDINGS_exp16.md` for the
pattern). The provenance rule is documented in the repo root README.
