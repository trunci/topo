# Experiment 17 — Grounding heads, Phase A (pre-stated analysis plan)

**Written 2026-07-03, before any analysis code was run.** Phase A is
*exploratory* (hypothesis-generating for a confirmatory Phase B), so it carries
pre-stated questions and statistics rather than GREEN/RED verdicts; anything
whose bootstrap CI clears its null becomes a pre-registered Phase B hypothesis.

## Data (all on disk; no new model passes)

`results/exp16_{distractor,gold}_features.parquet` — the same 200 HotpotQA
bridge items answered under both context geometries, with per-head (1024)
answer→context attachment (`ph_mtd`, low = answer attaches cheaply to the
prompt) and per-head response entropy (`ph_resp_ent`), plus confidence,
correctness, and geometry metadata. Items join on `id`.

## Questions and planned analyses

**A1 — Do stable per-head attachment signatures exist?** For each head,
Spearman correlation of its `ph_mtd` across the two geometries over the 200
shared items. Null: permutation of item alignment. Report the distribution,
BH-corrected per-head significance, and the depth (layer) profile of the most
stable heads. Motivation: a "grounding head" must measure something about the
(question, context, answer) relation that survives a 10× change in context
geometry.

**A2 — Does per-head attachment predict context sway?** Label each item
*divergent* if the generated answers under the two geometries do not match
(primary label: loose — neither normalized answer contains the other;
secondary: strict normalized mismatch). Divergence = the distractor context
changed the model's answer = context won or lost against memory. Probe:
fold-internal head-selected scalar (exp16 machinery, top 10 heads) on
distractor-condition `ph_mtd`, vs baselines: confidence margin, pooled MTop-Div,
mean response entropy, sequence length, and the same head-selection applied to
`ph_resp_ent` (the first-order twin — attachment must beat it to claim
structure-specific signal). Item bootstrap CIs (B = 10,000). Features use the
distractor condition only; the label uses both conditions' outputs — no leakage.

**A3 — Does attachment predict robustness to distractors?** On the subset the
model gets right under gold contexts, predict whether it *stays* right under
distractors, from distractor-condition `ph_mtd` (same probe machinery and
baselines). This is the applied RAG question: will added junk context break
this answer?

**A4 — Head identity.** Are A2's selected heads the A1-stable heads? Depth
histogram of the top heads (retrieval-heads literature predicts mid-depth
concentration).

## Underpowered rule

Any binary label with base rate outside [0.15, 0.85] is flagged UNDERPOWERED
and its probe is reported but not interpreted.

## Phase B promotion rule

An analysis is promoted to a confirmatory Phase B hypothesis iff its
head-selected AUC bootstrap CI95 lower bound clears 0.5 AND it beats the
response-entropy twin by ΔAUC bootstrap one-sided p < 0.05.

## Results (generated by compute_stats_exp17 from results/exp17_stats.json; do not edit)

**A1 — stability.** Median cross-geometry Spearman ρ = 0.599; 1024/1024 heads individually significant (BH < .05). Per-head attachment signatures survive the 10× context change. Caveat: shared item-level factors (answer form, question) inflate this; it is an upper bound on head-intrinsic stability.

**A2 — context sway (divergence rate 0.425).**

| predictor | AUC [CI95] |
|---|---|
| head-selected MTop-Div | 0.800 [0.736, 0.858] |
| head-selected response entropy (twin) | 0.808 [0.747, 0.864] |
| pooled MTop-Div (3 scalars) | 0.798 [0.737, 0.858] |
| confidence margin | 0.670 [0.592, 0.743] |
| sequence length | 0.464 [0.382, 0.548] |

MTop-Div vs entropy twin: ΔAUC = -0.009 (one-sided p = 0.7401) — attachment does NOT beat its first-order twin.

**A3 — robustness (n = 130, stays-correct rate 0.808).** head-selected MTop-Div 0.646 [0.507, 0.777] vs confidence 0.615 [0.497, 0.728] — suggestive, underpowered-adjacent.

**A4 — identity.** 22 heads selected across A2 folds; overlap with top-50 stable heads: 0. Predictive heads are not the stable heads; selected heads spread over early/mid/late layers.

## Phase A conclusion

The **phenomenon is real and strong**: per-head attention signatures of the generated answer predict whether distractor context sways the model's answer at AUC ≈ 0.80, far beyond confidence (≈ 0.67), and it is NOT a length artifact (seq-len AUC ≈ 0.46). But per the promotion rule, the *topological* construction is not what carries it: response entropy does equally well (ΔAUC ≈ 0, p = 0.74) — the audit's recurring lesson, reproduced in the new program on day one. Phase B is promoted with the honest framing: **per-head attention statistics (structure- agnostic) as a context-sway meter**, validated against ground-truth provenance labels (NoContext condition + span-resolved attachment), with topology retained only as one candidate featurization among cheap ones.
